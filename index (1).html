Installing Quizzy

Quizzy is installed directly from this file rather than an app store, so it takes a few extra taps.

Download the file

Tap the download button above. Quizzy.apk will save to your phone's Downloads folder.

Allow this source

Open the downloaded file. If Android blocks it, tap Settings and turn on "Allow from this source" for your browser.

Install

Go back and tap Install. This usually takes a few seconds.

Open Quizzy

Tap Open, and you're straight into your first quiz.

Why the extra steps? Android only allows an app to install itself automatically from the Play Store. Any APK downloaded from a website has to be opened and confirmed by hand — that's a device-level safeguard so no website can install anything without you seeing it happen.

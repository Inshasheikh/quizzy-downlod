# quizzy-downlod

Ye repository **Quizzy** Android app ki files aur ek web page host karti hai.

## 📁 Files
- `Quizzy.apk` - Android app ki installation file.
- `index (1).html` - App download ya info ke liye ek web page.
- `logo.png` - App ka logo.

## 📥 Download aur Installation
1. Is repository se `Quizzy.apk` file download karo.
2. Apne Android device par file ko open karo.
3. Agar puchhe toh "Unknown sources" se install karne ki permission do.
4. Installation complete hone ke baad app launch karo.

## 🌐 Web Page
`index (1).html` file ko kisi bhi browser mein open karke dekh sakte ho. Ye shayad app ka promo ya download page hai.
